# QuizMaster

Клон Quizlet без подписки и лимитов. Все режимы изучения открыты, аккаунт не нужен —
данные хранятся локально в браузере (`localStorage`), поэтому сайт бесплатно работает
на статическом хостинге и ничего не отправляет на сервер.

## Возможности

**Учебные модули**
- Создание и редактирование модулей, перестановка карточек, обмен столбцов местами
- Массовый импорт: вставка списка с разделителем «тире», табуляцией, запятой или своим символом
- Папки с цветами, избранные термины (звёздочки), поиск по модулям и по всем терминам
- Языки термина и определения — для корректной озвучки (Web Speech API)

**6 режимов изучения**
| Режим | Что делает |
|---|---|
| Карточки | 3D-переворот, перемешивание, автопрокрутка, «знаю / повторить», озвучка |
| Заучивание | Адаптивные раунды по 7 карточек: выбор ответа для новых слов, ввод — для знакомых |
| Письмо | Ввод с клавиатуры, опечатка в 1–2 символа засчитывается как «почти верно» |
| Диктант | Слово читается вслух, нужно написать его по памяти |
| Тест | Настраиваемый экзамен: выбор, ввод, «верно/неверно», соотнесение + проверка с разбором |
| Подбор | Игра на время: соединить пары, штраф 1 с за ошибку, личный рекорд |

**Прогресс**
- Алгоритм интервального повторения (система Лейтнера, 5 уровней)
- Статусы терминов: новое → изучается → знакомо → выучено
- Серия дней, карта активности за 12 недель, история тестов, рекорды «Подбора»

**Прочее**
- Тёмная и светлая темы, адаптив под телефон, горячие клавиши
- Экспорт/импорт всей библиотеки в JSON

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` | Перевернуть карточку |
| `←` / `→` | Предыдущая / следующая карточка |
| `S` | В избранное |
| `1` / `2` | «Повторить» / «Знаю» (карточки) |
| `1`–`4` | Выбрать вариант ответа (заучивание) |
| `/` | Фокус на поиск |

## Запуск локально

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # продакшен-сборка
```

## Стек

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · lucide-react

## Где лежат данные

Всё в `localStorage` под ключом `quizmaster.state.v1`, по одному хранилищу на браузер.
Чтобы перенести библиотеку на другое устройство: **Настройки → Скачать копию (JSON)**,
затем на новом устройстве — **Загрузить из файла**.
